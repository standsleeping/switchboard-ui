# switchboard-ui examples

These examples show the same island contract implemented three ways. In every case, Python builds the page with `workbench` and renders it with `render_document`, one island publishes a count topic, and another island subscribes to it.

The package API stays the same:

```javascript
mount(element, props, bus) => teardown
```

## Vanilla DOM

No JavaScript framework and no build step.

```bash
uv run python examples/vanilla/server.py
```

Open <http://127.0.0.1:8001>.

## Web Components

Custom elements with shadow DOM, mounted through the same adapter contract.

```bash
uv run python examples/web-components/server.py
```

Open <http://127.0.0.1:8002>.

## React

The page is still generated by Python; Vite handles only the React island bundle for this example.

```bash
cd examples/react
npm install
npm run dev
```

Open the URL printed by Vite, normally <http://127.0.0.1:5173>.
